❓ Frequently Asked Questions

How do I create a game? ▼
Click on "Editor" in the navigation bar. Use the visual editor to place ground, platforms, spikes, coins, enemies, and more. Click "Play Test" to try your game, then "Upload" to share it with the community.
Can I upload my own HTML games? ▼
Yes! Go to the Upload page and either paste your complete HTML game code or provide a URL to your hosted game. The HTML is stored in Firestore and served via blob URL.
Is GameHub free to use? ▼
Absolutely! GameHub is completely free. You can play games, create games with the editor, upload your own games, and use all features without paying anything.
What game types are supported? ▼
The editor supports platformer-style games with ground, platforms, spikes, coins, enemies, springs, and goal flags. You can also upload any HTML/JavaScript game via URL or code.
How do I become an admin? ▼
Admin access is managed by the site owner. If you need admin access, contact the site administrator. Admins can approve/reject games, feature games, and manage the platform.
What controls does the editor game use? ▼
Arrow keys or WASD to move, Space or Up arrow to jump. The editor also supports keyboard shortcuts: G (ground), P (platform), S (spike), C (coin), V (player), E (enemy), F (flag), B (spring), X (eraser).
Can I download my game? ▼
Yes! In the editor, click "Download" to save your game as a standalone HTML file. You can host it anywhere or share it directly.
How does the approval system work? ▼
When you upload a game, it may be sent for admin review depending on settings. Admins approve or reject games from the Admin Panel. Approved games appear on the homepage for everyone to play.
