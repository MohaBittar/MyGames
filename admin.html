🛠 First-time setup

  1. Firebase Console → Authentication → Get started → Email/Password → enable.
  2. Authentication → Users → Add user → your admin email + password.
  3. Firestore Database → Create database (production mode).
  4. Copy the security rules below → Firestore → Rules tab → paste → Publish.
  5. Hosting the site? Add your domain under Authentication → Authorized domains.
